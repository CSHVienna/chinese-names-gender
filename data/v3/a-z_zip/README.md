Folder: **a-z_zip**

All possible Chinese given names created by 8,096 characters, including both single-character and two-characters names.

File example: `nameDictionary_a.csv.gz` stores the subset of the name dictionary where the eng column begins with the letter “a”.

| column              | meaning  | creator                                                |
| --------------------- | ------- | ------------------------------------------------------ |
| id | unique id for each name | Liuhuaying Yang  |
| name | unique Chinese name | Liuhuaying Yang  |
| pinyin | name in pinyin with tones | Liuhuaying Yang  |
| eng | name in pinyin without tones | Liuhuaying Yang  |
| NLen | number of characters | Liuhuaying Yang  |
| NU | NU value | Liuhuaying Yang  |
| NG | NG value | Liuhuaying Yang  |

- **Number of files**: 23 (from letter a to z, except i, u, v)
- **Total number of names**: 65,553,312
- **Total number of single-character names**: 8,096
- **NU, NG values**: Model by Han-Wu-Shuang Bao
