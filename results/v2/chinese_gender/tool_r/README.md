# Gender Data from ChineseNames R Package

This folder contains gender scores generated using the *ChineseNames R package*, collected by @liu.

## Source

- Tool: [ChineseNames](https://psychbruce.github.io/ChineseNames) (R package)
- Output: Gender score (NG) computed from character-level usage frequencies in male and female names.

## Format

- All files are `.csv`
- Each file includes at least: `character` or `givenname` and `NG` (gender score)

## Notes

- NG ranges from –1 (completely female) to +1 (completely male).
- Data was collected for research use. Refer to the package documentation for details.
