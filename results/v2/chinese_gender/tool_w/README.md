# Gender Data from Tool W

This folder contains gender labels collected from the *Chinese Tools Gender Guesser* by @lisette-espin.

## Source

- Tool: Chinese Tools Gender Guesser (https://www.chinese-tools.com/tools/gender-guesser.html)
- Output: Binary gender labels (`male`, `female`) based on Chinese given names or characters.

## Format

- All files are in `.csv` format.
- Each file includes at least: `givenname` (or `character`) and `gender`.

## Notes

- Data was collected automatically for research use.
- Use in accordance with the source site's terms of service.
