# Resources for Web Scraping Tool W

This folder contains supporting files for scraping data from Tool W:

- **`proxies.txt`**: A list of HTTP proxy IP addresses, used to rotate connections and avoid rate limits.
- **`agents.txt`**: A collection of browser user-agent strings to mimic different client requests.

**Format**:  
Each file is plain text, with one entry per line.

**Note**:  
These resources are used to reduce blocking and improve scraping reliability. Use them ethically and in accordance with the target website's terms of service.
